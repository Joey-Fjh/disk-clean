# Disk Clean v0.1.0 Release Notes (RC)

**发布日期**：2026-08-31  
**定位**：v0.1.0 Release Candidate — 可安装试用，非正式稳定版

## 亮点

- 统一五步清理流程：扫描 → 智能分析（可选）→ 建议 → 移入回收站 → 自动复核
- 无 API Key 可完成本地规则扫描与回收站清理
- 配置 Provider 后可启用 Agent 分析与来源标签
- **我的经验**：用户确认保留项，下次扫描归入建议保留
- 扫描 session 测量缓存提升重叠目录性能

## 安装

1. 运行 `Disk Clean-0.1.0-x64.exe`
2. 选择安装目录（非 one-click）
3. 从开始菜单或桌面快捷方式启动

> 安装包**未代码签名**，Windows SmartScreen 可能显示警告，属预期行为。

## 首次使用

1. 选择盘符 → **开始清理扫描**
2. 无 Key：扫描完成后直接查看五类结果
3. 有 Key：设置 → 模型连接 → 扫描后自动 Agent 分析
4. 勾选项目 → 确认 → 移入回收站 → 等待自动复核

## 回收站语义

- 默认移入 **Windows 回收站**，非永久删除
- 卸载本程序**不会**自动清空回收站或删除用户文件

## 隐私与模型

- 发送给模型的路径经脱敏摘要，不含完整绝对路径与用户名
- API Key 仅存本地加密配置，不打入安装包

## 已知限制

- RC 未做代码签名
- 跨扫描目录缓存未启用
- 识别提示经验 API 已就绪，UI 创建入口仅保留排除项
- 深色/浅色主题待更广泛实机验证

## 升级说明

覆盖安装即可；用户配置与经验位于 `%APPDATA%/disk-clean/config/`。
