# 产品决策

记录 2026-08-19 讨论结论，方便换电脑后继续，不必重讲。

## 定位

做 **规则驱动的 Windows 磁盘清理工具**，不是通用 Agent，也不是杀毒软件。

长期北极星可以是「小型系统管家」（清理 → 整理/移动 → 卫生检测），但第一期只做清理。

参考对象：火绒 / 电脑管家的**清理模块**——规则扫描、分类展示、用户确认后删除。

## 核心逻辑

```
规则库（扫哪里、归哪类）
  → 扫描引擎（列路径、算大小）
  → 三分类 UI
  → 用户勾选 + 二次确认
  → Executor 执行（优先进回收站）
  → 审计日志
```

这和此前「让 AI 扫、分类、再调工具删除」是同一套逻辑。差别只是：

- 以前：对话壳 + AI 临场决定扫什么
- 现在：桌面壳 + 规则固化进配置，可重复、可换机器

## 三分类

| 类别 | 含义 | UI 策略 |
|------|------|---------|
| safe | 缓存、临时文件、安装包残留等，删了一般可再生 | 默认可勾选 |
| recommended | 微信/QQ 预览缓存、Downloads 旧安装包等，可能影响体验 | 默认不勾选 |
| dangerous | 觉得该处理，但需要人审；系统相关或用户数据 | **只告知，默认不删** |

任何删除都必须用户同意。危险项即使列出也不提供常规删除。

## 安全底线

- 白名单扫描：只扫规则里的路径，不全盘盲删
- 永不触碰：`System32`、`SysWOW64`、Boot、注册表等系统关键目录
- 删除优先进回收站，不直接永久删除
- 扫描报错（权限拒绝）要跳过并记录，不能因此崩系统

## 不做 / 暂缓

- 第一期不接 AI / Agent。规则能覆盖「扫什么、怎么分类、删不删」
- 不做实时杀毒、驱动拦截、病毒库
- Liquid 下拉小组件、托盘、移动整理、启动项体检：后期扩展，架构预留即可

## 技术方向（暂定）

- 桌面端优先，后续可加小组件壳
- 候选：Electron（主窗口 + 以后透明小组件）
- 扫描/执行放主进程；UI 只展示和确认
- 规则放 `config/rules.json`，可独立更新

## AI 什么时候才需要

只有规则覆盖不了时才考虑，例如自然语言「清微信但别动聊天记录」、解释陌生路径。即便接入：

- AI 只做参谋（解释、建议、生成方案）
- 不能直接调删除
- 删除仍走 Executor + 用户确认
